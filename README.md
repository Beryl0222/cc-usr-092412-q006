# 公园节令联名履约

节令活动联名礼盒（公园文创 × 食品作坊 × 公益机构）的组合承诺与重组服务。
处理某批食品临时缺货或检测结论变化时，已通过线下摊位、团购、公益赠送分别承诺出去的礼盒如何安全重组，
并保证活动结束后每个礼盒"装了什么、贴了哪版标签、额度怎么变、谁来补偿"都可解释。

## 设计原则

事件溯源：所有状态变化都是仅追加事件（`src/store.js`），事件一经提交冻结、不可原地改写；
业务更正产生后继记录。一次业务动作的多个事件在同一批次原子提交——校验全部通过才落库，任一失败整体回滚。

以下事实分别使用独立聚合留痕，互不覆盖：

| 聚合 | 留痕内容 |
| --- | --- |
| `component_lot` 组件批次 | 合作方、总量、预留/消耗台账、过敏原、冻结（缺货/检测）与解除 |
| `assembly_version` 装配版本 | 某版本礼盒由哪些批次组件、各多少构成 |
| `label_snapshot` 标签快照 | 不可变的标签版本与过敏原声明；更正只能出新版本 |
| `channel_quota` 渠道额度 | 摊位/团购/公益三渠道、按装配版本分别设额，带完整变动台账；公益额度带保护标记 |
| `bundle_commitment` 组合承诺 | 渠道、数量、装配版本、标签版本、迁移/冻结历史 |
| `reconfiguration_plan` 重组方案 | 每项承诺的释放/占用方案、可行性、双闸门审批、合作方逐项表态、执行结果 |
| `gift_box` 礼盒实例 | 实际装入的批次与数量、标签版本、领取状态、影响通知 |
| `clearance_batch` 清算批次 | 按业务标识合并的装配回执与离线核销、扣留、暂停/恢复、清算 |
| `partner_liability` 合作方责任 | 补偿依据、份额、金额与补救完成情况 |

事件类型与聚合类型的完整枚举见 `contracts/domain.schema.json`。

## 核心流程

1. **建账**：组件批次入库（带合作方与过敏原）→ 留存标签快照 → 发布装配版本 → 各渠道按装配版本开放额度。
   装配发布时即校验标签过敏原是否覆盖全部组件，防止"标签失真"在源头发生。
2. **承诺**：`promise` 同时原子占用组件批次与渠道额度；任一不足或渠道类型不匹配则拒绝且不留痕。
3. **缺货/检测变化**：批次被 `quarantine` 后，`affectedCommitments` 给出受影响的未履约承诺；
   `proposeReconfiguration` 为每项承诺计算释放哪些旧组件、占用哪些新组件、目标额度、需表态的合作方与当前可行性。
4. **双闸门 + 合作方表态**：
   - 食品负责人确认标签（`approveLabel`，再次校验过敏原覆盖）；
   - 渠道负责人确认配额（`approveQuota`，按确认当下的额度复核）；
   - 新供组件涉及的合作方逐项同意/拒绝（`partnerRespond`）。
   缺少任一闸门，方案不得执行。
5. **执行重组**（`executePlan`）：
   - 原子释放旧组件、占用新组件，并在渠道额度台账上迁出/迁入；
   - 某合作方拒绝、尚未表态，或执行时库存/额度/冻结条件不再成立的，**只冻结该受影响组合**，其余照常迁移；
   - 被冻结组合仍持有旧组件占用，找到替代供应后可凭**新方案**恢复；
   - 已装配、已领取的礼盒**保持原装配事实**，只追加影响通知（含新增过敏原提示）。
6. **公益保护**：公益额度带保护标记，重组只能在同类型渠道内迁移；商业渠道目标额度不足时冻结，
   绝不占用公益保留量。
7. **离线核销**：装配回执与离线核销按业务标识（渠道）合并入同一清算批次；
   编号相同但内容哈希变化的回执被扣留、清算暂停；全部扣留处置（替换转正/废弃）后才恢复清算。
8. **事后解释**：`explainBox(box_id)` 汇总礼盒实物构成（含合作方）、标签版本、承诺迁移历史、
   渠道额度台账与补偿责任；责任通过 `assignLiability` / `completeRemedy` 独立留痕。

## 目录

- `contracts/domain.schema.json`：领域事件信封、事件类型与聚合类型契约。
- `src/store.js`：仅追加事件存储、批内版本分配与原子提交。
- `src/model.js`：事件投影（读模型）与库存/额度派生查询。
- `src/service.js`：组合承诺与重组应用服务（业务规则、双闸门、执行、清算、解释视图）。
- `src/validator.js`：基础事件信封校验。
- `data/`：联调样例（含一条重组迁移样例）。
- `tests/`：信封契约与全流程场景测试。

## 本地检查

```bash
npm test     # 16 个测试：承诺占用、双闸门、原子迁移、公益隔离、部分冻结、回执合并/暂停、事后解释等
npm run build
```

不需要外部服务，单个 Linux 容器内即可运行。
